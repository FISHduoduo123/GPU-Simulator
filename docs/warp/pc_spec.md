# PC（程序计数器）规格书 —— GPU 模拟器

- 项目：GPU 模拟器
- 模块：程序计数器 PC + 与 BRU / 取指通道的交互
- 状态：**接口与行为已确认；实现代码待用户明确说“写代码”后才编写**
- 更新日期：2026-11-24
- 依据：用户本轮规定（`jump_req=1` → 下周期 `PC=jump_addr`，否则默认 `PC+2`）+ 确认参数

---

## 1. 端口（已确认）
| 端口名 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| `jump_addr` | 输入 | **16bit** | 跳转目标地址（来自 BRU 的 `bru_jump_addr`） |
| `jump_req` | 输入 | 1bit | 跳转请求：`1` → 下周期取跳转地址 |
| `pc` | 输出 | **16bit** | 当前程序计数器值 |

- **无独立使能/保持端口**：每周期必定更新，仅由 `jump_req` 决定 +2 还是跳转。
- PC 输出同时作为取指地址源：当前接内部 `imem[pc>>1]`，并预留作共享取指通道的 `g_raddr`（见 `docs/memory/mem_interface_spec.md` §5/修订 E）。

## 2. 行为（已确认）
- **时钟**：与系统同拍（上升沿同步更新）；**异步复位到 0**。
- 每周期 `next_pc =`：
  - `jump_req == 1` → **`jump_addr`**
  - 否则 → 默认 `pc + 2`；若 `pc + 2` 溢出 16bit（大于 `0xFFFF`）则 **置 0**（不是自然回绕到 `0x0001`，而是溢出归零）。
- PC 递增步长恒为 **+2**（一条 16bit 指令占用 2 个地址空间）。

## 3. 与 BRU 的连接（已确认）
```
bru_jump_req  ──► jump_req
bru_jump_addr ──► jump_addr
pc            ──► (取指地址 / 共享取指通道 g_raddr)
```
- BRU 决策出 `bru_jump_req`/`bru_jump_addr` 后，PC 在下一周期按本规格更新。

## 4. 悬置项（不猜测）
- PC 与数据访存地址（17bit）之间的**地址空间口径**（16bit PC 地址空间 vs 17bit 数据地址）—— 待确认。
- 停止/暂停（halted/done）时 PC 是否保持 —— 待确认。

# 程序计数器（PC）—— GPU 模拟器
> 16bit PC：`jump_req=1` 时取跳转地址，否则 +2，溢出置 0。

- 模块：warp 级 / 程序计数器
- 状态：接口与行为已确认（`src/system.rs` 内联实现的取指/推进逻辑）
- 更新日期：2026-11-26
- 依据：用户规定（`jump_req=1` → 下周期 `PC=jump_addr`，否则 `PC+2`）+ 确认参数
- 关联：`docs/warp/bru_spec.md`、`docs/memory/memory_spec.md`

## 1. 概述
- 4 个线程核心共享 1 个 PC，天然锁步执行同一条指令。
- PC 同时作为共享取指通道的地址源。

## 2. 端口与接口
| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| `jump_addr` | 输入 | 16bit | 来自 BRU `bru_jump_addr` |
| `jump_req` | 输入 | 1bit | `1` = 下周期取跳转地址 |
| `pc` | 输出 | 16bit | 当前 PC；同时驱动取指地址 |

- 无独立使能/保持端口：每周期必定更新，仅由 `jump_req` 决定。
- 取指地址映射：`pc[15:0]` 直连 17bit 读地址端口的 `[15:0]`，`[16]` 接 0（见 `docs/memory/memory_spec.md`）。

## 3. 功能与行为
- **时钟**：与系统同拍（上升沿同步更新）；**异步复位到 0**。
- 每周期：
  - `jump_req=1` → `next_pc = jump_addr`；
  - 否则 `next_pc = pc + 2`；若 `pc+2` 超过 `0xFFFF`，**置 0**（不是自然回绕）。
- 步长恒为 **+2**（16bit 指令占 2 个地址空间）。

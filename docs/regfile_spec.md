## 1. 总体规格

| 项目 | 规格 |
|---|---|
| 寄存器数量 | 16 个，编号 `r0–r15`，地址宽 4bit |
| 每寄存器位宽 | 16bit（总存储 256bit） |
| 读端口 | 4 个（A/B/C/D），每端口：4bit 读地址输入 + 16bit 数据输出 |
| 写端口 | 1 个：4bit 写地址 `waddr` + 16bit 写数据 `wdata` + 1bit 写使能 `wen` |
| 读方式 | 组合读（4 端口可同时读，允许同地址） |
| 写方式 | 同步写，`clk` 上升沿生效 |
| 时钟 | `clk` 上升沿有效 |
| 复位 | **异步复位** `rst`，**初始全为 0** |

## 2. 时序语义（已确认）

- 读为组合逻辑：任意时刻 `rdata_x = regs[raddr_x]`，x ∈ {a,b,c,d}。
- 写只在 `clk` 上升沿采样：若 `wen=1`，则 `regs[waddr] ← wdata`。
- **“上升沿后读新值、上升沿之前读旧值”**：同周期“写 rX 且读 rX”时，沿前读到旧值、沿后读到新值 → **不需要写优先旁路（bypass）**。
- 异步复位有效时，所有寄存器立即清 0（不受时钟约束）。

## 3. 软件模拟模型（用代码模拟电路行为，内部可优化）

对外端口与时序语义保持“电路化”；内部用软件友好结构等价实现：

- **状态**：一块连续存储 `regs[0..15]`，元素 16bit（等价于 16 个 DFF 的 Q）。
- **读端口**：4 个 16:1 MUX → 4 次 **O(1) 数组索引**，无需译码器/MUX 实体：
  - `rdata_a = regs[raddr_a]`，b/c/d 同理。
- **写端口**：写请求先暂存为 pending，在**周期边界（模拟的时钟上升沿）统一提交**：
  - 周期内所有组合读看到旧值；周期结束（上升沿）时执行一次 `regs[waddr] = wdata`。
  - 严格等价于边沿触发寄存器 + 组合读，且同周期多写不会乱序。
- **优化点**：

| 电路实现 | 软件模拟 | 收益 |
|---|---|---|
| 16 个 DFF16E | `[u16; 16]` 一维数组 | 连续内存、缓存友好 |
| 4→16 写译码器 | 一次地址比较 | 写路径 O(1) |
| 4 个 16:1 MUX（16bit 宽） | 4 次数组索引 | 读路径 O(1)，端口数无成本 |
| 边沿采样写入 | 周期末一次性提交 pending write | 天然保持“沿后读新值”语义 |

- **可选调试增强**（不影响语义）：保留上一拍快照 `prev_regs`，周期结束时对比哪些寄存器在上升沿被改写，便于后续波形/调试输出。

## 4. 逻辑方程（规格级，非实现代码）

```
wsel[i]  = (waddr == i)
wen_i    = wen & wsel[i]
regs[i]  在 clk 上升沿:  rst ? 0 : (wen_i ? wdata : regs[i])   // 异步复位时立即为 0
rdata_a  = OR_i (raddr_a==i) ? regs[i] : 0                      // 16选1，b/c/d 同理
```

## 5. 对外接口与和线程核心的连接构造

端口：
- 输入：`clk`、`rst`（异步）、`wen`、`waddr[3:0]`、`wdata[15:0]`、`raddr_a/b/c/d[3:0]`
- 输出：`rdata_a/b/c/d[15:0]`

与核心的连接：
- 读端口 A/B/C/D → **源操作数 1/2/3/4**，ID 段送来的寄存器号在本周期直接组合取值。
- 写端口 ← **回写多路选择器（WB MUX）**：`waddr ← 目的寄存器号`，`wdata ← 回写数据`，`wen ← 回写有效`；回写数据来源（ALU / LDR / 原子 / LDI 等）在后续搭建执行部件时定义。
- `clk` / `rst` 与线程核心共用。

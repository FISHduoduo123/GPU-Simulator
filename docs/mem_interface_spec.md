# 内存接口（Memory Interface）规格书 —— GPU 模拟器

- 项目：GPU 模拟器
- 模块：线程核心 ↔ 外部存储/访存通道
- 状态：**接口端口已确认；实现代码待用户明确说“写代码”后才编写**
- 更新日期：2026-11-23
- 依据：用户本轮规定 + `docs/thread_core_spec.md` §5（访存接口骨架）

---

## 1. 接口模型（已确认）
- **单请求模型**：每个周期最多一个访存请求，共用同一组地址/读写/原子控制信号。
- **两个数据端口** = 一个**输入**（写数据，核心 → 内存）+ 一个**输出**（读数据，内存 → 核心），各 **16bit**。

## 2. 端口清单

| 端口名 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| `mem_data_in` | 输入（到内存） | 16bit | 写数据（核心 → 内存） |
| `mem_data_out` | 输出（来自内存） | 16bit | 读数据（内存 → 核心） |
| `mem_addr` | 输出 | 17bit | 访存地址 |
| `mem_ren` | 输出 | 1bit | 读使能（独立信号） |
| `mem_wen` | 输出 | 1bit | 写使能（独立信号） |
| `mem_atomic` | 输出 | 3bit | 原子信号：bit2=有效，bit1:0=类型 |
| `branch_out` | 输出 | — | 给外部 **BRU** 的分支信息 —— 已独立成文档：见 `docs/branch_interface_spec.md` |

- **请求有效** = `mem_ren \| mem_wen \| mem_atomic[2]` 任一为 1（无需额外请求端口）。
- 读写信号为**独立两信号**（`mem_ren`、`mem_wen`），不使用单一读写方向位。
- 原子操作（ATADD/ATSWAP/ATCAS）**后续详细讨论再展开**，本期只预留原子信号端口骨架，复用数据端口方案已取消。

## 3. 原子信号编码（已确认）
| `mem_atomic` | 含义 |
|---|---|
| `000` | 无原子操作 |
| `101` | ATADD（有效=1，类型=01） |
| `110` | ATSWAP（有效=1，类型=10） |
| `111` | ATCAS（有效=1，类型=11） |

- 即 `mem_atomic = {valid, type[1:0]}`：`valid=0` 或 `type=00` 表示无原子。
- **ATCAS 的 cmp/new 端口暂不定义**：不复用数据端口；具体端口与语语义将在原子操作详细讨论时确定（见 §6 悬置项）。

## 4. 访存请求语义
- **读**（LDR/POP 等）：`mem_ren=1`，`mem_addr=地址`，读结果通过 `mem_data_out` 返回核心。
- **写**（STR/PUSH 等）：`mem_wen=1`，`mem_addr=地址`，写数据通过 `mem_data_in` 送往内存。
- **原子**（ATADD/ATSWAP/ATCAS）：`mem_atomic.valid=1` + 类型，地址/数据走同一组端口。
- 每周期至多一个请求：`mem_ren`、`mem_wen`、`mem_atomic.valid` 互斥（协议展开时保证）。

## 5. 与指令的对应
- op=`1010` 访存段：`0000 STR / 0001 LDR / 0010 PUSH / 0011 POP / 0100 ATADD / 0101 ATSWAP / 0110 ATCAS`。
- 地址来源（如 `rx(a)+rx(off)`）与栈（r15）语义在**访存协议**展开时定义。
- PUSH/POP 使用栈基址寄存器 r15，仍走本接口（地址由栈指针计算）。

## 6. 悬置项（不猜测）
- **寻址粒度**：17bit 地址按字节还是按 16bit 字 —— **暂不考虑**，后续再定。
- **分支输出端口 `branch_out` 到 BRU**：已定，独立文档见 `docs/branch_interface_spec.md`（`br_jump_addr`16bit / `br_op`4bit / `br_cond`4bit / `br_uncond_attr`1bit / `br_func`1bit / `br_mask`1bit）。
- **原子操作**（含 ATCAS 的 cmp/new 端口）：**后续详细讨论再实现**，不复用数据端口。
- 访存响应时序（组合单拍返回还是多拍握手）—— 待协议展开。

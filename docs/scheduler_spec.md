# GPU 全局调度器（Global Scheduler）—— GPU 模拟器

> 一句话作用：把内存中的 block 列表按 FIFO 依次发射到若干 warp 槽位上执行。

- 模块：GPU 全局调度器（位于 warp 之上，GPU 顶层）

## 1 概述

全局调度器是 warp 之上的上层：管理多个 warp 槽位，每个槽位是一个现有 warp（4 核 + BRU + PC + 内存接口）的实例。启动时从命令行/启动参数取得 grid 参数与 block 总数，从内存读取 block 列表，按 FIFO 把 block 发射到空闲槽位。

## 3 功能与行为

- **调度对象（已确认）**：block → 多个 warp 槽位。
- **槽位数（已确认）**：先定 **4 个** warp 槽位。
- **规模（已确认）**：1 block = 1 warp = 4 核，固定。
- **输入来源（已确认）**：内存中的 block 列表（grid 参数 + 程序入口）；block 总数/grid 由命令行/启动参数传入。
- **策略（已确认）**：**FIFO 先就绪先发**。
- **关系（已确认）**：上层，调度器管多个 warp，每个 warp 就是现有 4 核结构实例。
- **槽位释放（待细说）**：block 执行结束后槽位何时释放、如何发射下一个。

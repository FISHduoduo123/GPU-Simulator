# 内存（访存接口 + 测试内存模块）—— GPU 模拟器
> 两层：① 核心 ↔ 内存的访存接口；② 测试阶段的 64KB 内存模块。存储采用**大端**，指令 24bit。

- 模块：内存
- 状态：接口与模块行为已确认；`src/memory.rs` 已实现 32bit 读写 + 字节使能（常量接线：核心 `be=01`、取指 `be=11`）
- 更新日期：2026-11-26
- 依据：用户规定（4 地址端口 + 4 组读写控制一一对应 4 核；64KB / 粒度 16bit / 4 组读写 + 1 读接口 / 大端 / 指令 24bit）
- 关联：`docs/core/thread_core_spec.md` §3.4、`docs/warp/pc_spec.md`、`docs/warp/bru_spec.md`

## 1. 概述
- **4 核心一对一 + 1 条全局共享副读通道**：每核独立端口组 `k`（k=0..3）；副读通道不归属任何核心。
- 副读通道 = **共享取指通道**：返回的指令广播给 4 核（SIMT 锁步）。
- 响应时序：**单周期、无握手**。
- 原子操作（ATADD/ATSWAP/ATCAS）**不纳入本接口**，后续详谈。

## 2. 端口与接口
### 2.1 核心侧：每核端口组 k（以核心为视角）
| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| `addr_k` | 输出 | 17bit | 访存地址 |
| `wdata_k` | 输出 | 32bit | 写数据 |
| `ren_k` | 输出 | 1bit | 读使能 |
| `wen_k` | 输出 | 1bit | 写使能 |
| `rdata_k` | 输入 | 32bit | 读数据 |

- 请求有效 = `ren_k | wen_k`；读、写为独立两信号（无单一读写方向位）。

### 2.2 核心侧：全局共享副读通道（取指）
| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| `addr_in` | 输入 | 16bit | 全局地址输入（接全局 PC 的 `pc`） |
| `g_raddr` | 输出 | 17bit | 副读地址；`g_raddr[15:0]=addr_in[15:0]`、`g_raddr[16]=0` |
| `g_rren` | 输出 | 1bit | 副读使能 |
| `g_rdata` | 输入 | 32bit | 副读数据（内存→外部） |

### 2.3 测试内存模块：每核读写接口 k（以存储模块为视角）
| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| `addr_k` | 输入 | 16bit | 字节地址（本次首地址 X） |
| `wdata_k` | 输入 | 32bit | 写数据 |
| `be_k` | 输入 | 2bit | 字节使能（见 §3.2） |
| `rw_k` | 输入 | 1bit | 0=读，1=写（单条方向信号） |
| `rdata_k` | 输出 | 32bit | 读数据 |

### 2.4 测试内存模块：取指读接口
| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| `f_ren` | 输入 | 1bit | 取指读使能 |
| `f_addr` | 输入 | 16bit | 取指字节地址 |
| `f_rdata` | 输出 | 32bit | 取指数据（广播给 4 核） |

- 对应关系：`f_ren=g_rren`、`f_addr=g_raddr[15:0]`、`f_rdata=g_rdata`。

## 3. 功能与行为
### 3.1 请求语义
- **读**（LDR/POP 等）：`ren_k=1`，当拍经 `rdata_k` 返回并回写目的寄存器。
- **写**（STR/PUSH 等）：`wen_k=1`，数据经 `wdata_k` 写入。
- **取指**：`g_rren=1`，按 `g_raddr` 读，`g_rdata` 广播到 4 核指令端口。
- 指令对应：`op=1010`：`0000 STR / 0001 LDR / 0010 PUSH / 0011 POP / 0100 ATADD / 0101 ATSWAP / 0110 ATCAS`；PUSH/POP 用栈基址 `r15`。

### 3.2 字节使能 `be[1:0]`（大端，读写均生效）
`wdata_k[15:0]` ↔ 当前单元（字节 X、X+1）；`wdata_k[31:16]` ↔ +1 单元（字节 X+2、X+3）。

**写**
| `be_k` | 动作 |
|---|---|
| `11` | 当前与 +1 都写 |
| `10` | 只写 +1（`wdata[31:16]`→[X+2,X+3]） |
| `01` | 只写当前（`wdata[15:0]`→[X,X+1]） |
| `00` | 不写 |

**读**（未使能半字读为 0）
| `be_k` | `rdata_k` |
|---|---|
| `11` | 全 32bit |
| `10` | 低 16 位为 0，高 16 位=[X+2,X+3] |
| `01` | 高 16 位为 0，低 16 位=[X,X+1] |
| `00` | 全 0 |

- **实现注记（2026-11-27）**：`src/memory.rs` `read32(addr,be)`（数据路径、小端：低 16 位=unit[addr]、高 16 位=unit[addr+1]）与 `write32(addr,be,wdata)` 按上表门控；取指路径用大端 `read32be(addr,be)`（`g_rdata=(unit[a]<<16)|unit[a+1]`）。常量接线：`BE_CORE=0b01`（核心）、`BE_FETCH=0b11`（取指），见 §3.4 与 `src/system.rs`。

### 3.3 大端字节序
- 每个 16bit 单元内：**低地址字节 = 高 8 位**（字节 X=`[15:8]`、X+1=`[7:0]`）。
- 32bit 数据同样低地址=最高字节：X=`[31:24]`、X+1=`[23:16]`、X+2=`[15:8]`、X+3=`[7:0]`。

### 3.4 系统接线约定
- **核心侧 4 组 `be_k` 恒接 `01`**：核心按 16bit 访问，只用低 16 位。
- **取指读接口 `be` 恒接 `11`**：完整读回 32bit。

### 3.5 指令在内存中的存放（24bit，大端）
- 指令 `I`：`op=I[23:20]` + `f1..f5`（`I[19:16]`…`I[3:0]`）。
- 跨两个 16bit 单元：
  - **低地址单元 `a`**（字节 a、a+1）：放 `I[23:8]`；大端 → 字节 a=`I[23:16]`、a+1=`I[15:8]`，`op` 在字节 a 最高半字节。
  - **高地址单元 `a+1`**（字节 a+2、a+3）：放 `I[7:0]` 于该单元**高 8 位**；大端 → 字节 a+2=`I[7:0]`、a+3=0。
- **取指重组**（上下 16 位交换）：`g_rdata = (unit[a] << 16) | unit[a+1]`；核心取高 24 位：`instr = g_rdata >> 8`。实现注记：模拟器 `src/system.rs` `fetch()` 用等价式 `instr = unit[a]<<8 | unit[a+1]>>8` 从**统一内存**取值（`.hex` 镜像与汇编程序都按此大端 2 半字装入）。

### 3.6 顶层装配
- **核心侧**：端口组 k 由 `ThreadCore.k` 提供（`addr/wdata/ren/wen`）；`rdata_k` 经 `apply_load` 同拍回写。
  - 注：规格 `wdata_k/rdata_k` 为 32bit，而当前 `ThreadCore` 访存数据为 16bit，待后续加宽对齐。
- **取指通道**：`addr_in ← PC.pc`；`g_raddr[15:0]=pc[15:0]`、`[16]=0`；`g_rdata → instr=g_rdata>>8` 广播 4 核。
  - 实现注记：模拟器 `GpuSystem` 已**统一内存取指**（`fetch()` 读 `mem[pc]`、`mem[pc+1]` 两个半字重组），PC=半字地址、顺延 +2；`.hex` 镜像经 `load_hex()` 写入同一内存（见 §3.5）。

## 4. 待确认 / 悬置
- **寻址粒度**：17bit 地址按字节还是按字。
- **对齐**：取指一次读 4 字节，要求 4 字节对齐；非对齐行为待说明。
- **冲突仲裁**：4 组同拍同地址的写读/写写顺序。
- **栈协议**：r15 栈基址增长/回退、PUSH/POP 方向。
- **原子**：ATADD/ATSWAP/ATCAS（含 cmp/new 端口）后续详谈。
- **存储介质**：按字节 `Vec<u8>` 还是按字。
- **PC 步长一致性**：+2 与 4 字节取指的换算。
- 项目级：接口形态/运行方式/验收标准（`docs/open_items.md` E1–E3）。

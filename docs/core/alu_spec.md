# 整数算数逻辑单元（ALU）—— GPU 模拟器
> `op=0100` 的 16bit 整数运算单元，2 源输入 + 单独目的地址，纯组合单周期。

- 模块：线程核心内部 / 整数 ALU
- 状态：已实现（`src/alu.rs`）
- 更新日期：2026-11-26
- 依据：`refs/GPU指令集.xlsx` 中 `op=0100` 段（func 4bit）
- 关联：`docs/core/regfile_spec.md`、`docs/core/thread_core_spec.md`

## 1. 概述
- 只处理 **`op=0100`** 的整数指令；FP16 见 FPU（`op=0101`），SEL（`op=0011`）单独处理。
- 操作数 16bit；ADD/SUB 16bit 回绕，MUL 取低 16bit。
- 纯组合、单周期出结果；写回由核心在时钟上升沿统一提交。

## 2. 端口与接口
| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| `a` | 输入 | 16bit | 源操作数 1（读端口 A） |
| `b` | 输入 | 16bit | 源操作数 2（读端口 B） |
| `func` | 输入 | 4bit | 运算选择（来自译码） |
| `dst` | 输入 | 4bit | 目的寄存器地址（单独给写端口 `waddr`） |
| `result` | 输出 | 16bit | 运算结果 → 回写 MUX → `wdata` |
| `wen` | 输出 | 1bit | 回写使能：`func=0011`(NOP) 时为 0，否则 1 |
| `flags` | 输出 | 10bit | 比较标志 → 标志寄存器 |

## 3. 功能与行为
### 3.1 func 编码
| func | 指令 | 语义 |
|---|---|---|
| 0000 | ADD | `a + b`（16bit 回绕） |
| 0001 | SUB / CMP | `a − b`（16bit 回绕），**并更新 10bit 标志**；CMP 即 SUB |
| 0010 | MUL | `a × b` 取低 16bit |
| 0011 | （空缺） | **当 NOP**：不写回、不更新标志 |
| 0100 | XOR | `a ^ b` |
| 0101 | XNOR | `~(a ^ b)` |
| 0110 | AND | `a & b` |
| 0111 | NAND | `~(a & b)` |
| 1000 | OR | `a \| b` |
| 1001 | NOR | `~(a \| b)` |
| 1010 | NOT | `~a`（单目，忽略 b） |
| 1011 | SHL | `a << shamt`，`shamt = b[4:0]`；≥16 → 0 |
| 1100 | SHR | `a` 逻辑右移（补 0），`shamt = b[4:0]`；≥16 → 0 |

### 3.2 标志（10bit，比较基准 `a`、`b`）
| bit | 标志 | 含义 |
|---|---|---|
| 0 | EQ | `a == b` |
| 1 | NE | `a != b` |
| 2 | LT | 有符号 `a < b` |
| 3 | GT | 有符号 `a > b` |
| 4 | LE | 有符号 `a <= b` |
| 5 | GE | 有符号 `a >= b` |
| 6 | ULT | 无符号 `a < b` |
| 7 | UGT | 无符号 `a > b` |
| 8 | ULE | 无符号 `a <= b` |
| 9 | UGE | 无符号 `a >= b` |

- 标志寄存器 10bit，异步复位全 0；**仅 `func=0001`（SUB/CMP）更新**。
- 条件判断（SEL/BRAF/HLTF 等）按指令集 Cond 编码从这 10bit 取位。

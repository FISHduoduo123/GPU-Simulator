# 算数逻辑单元（ALU）规格书 —— 基础线程核心

- 项目：GPU 模拟器
- 模块：基础线程核心 / ALU
- 状态：**规格已确认；实现代码待用户明确说“写代码”后才编写**
- 更新日期：2026-11-23
- 依据：`refs/GPU指令集.xlsx` 中 `op=0100` 算数逻辑计算段（func 4bit 区分）

---

## 1. 覆盖范围（已确认）
- **仅 op=0100 的整数算逻指令**；FP16（op=0101）另起 FPU 模块；SEL（op=0011）单独处理。
- func 编码（4bit）：

| func | 指令 | 语义 |
|---|---|---|
| 0000 | ADD | result = a + b（16bit 回绕） |
| 0001 | SUB / CMP | result = a − b（16bit 回绕），**同时更新 10bit 标志（对 a、b 比较）**。CMP 即 SUB，不单独区分 |
| 0010 | MUL | result = (a × b) **取低 16bit** |
| 0011 | （空缺） | **当作 NOP：不写回、不更新标志** |
| 0100 | XOR | a ^ b |
| 0101 | XNOR | ~(a ^ b) |
| 0110 | AND | a & b |
| 0111 | NAND | ~(a & b) |
| 1000 | OR | a \| b |
| 1001 | NOR | ~(a \| b) |
| 1010 | NOT | ~a（单目，忽略 b） |
| 1011 | SHL | a 左移 shamt；shamt = b 低 5bit；shamt≥16 时结果为 0 |
| 1100 | SHR | a **逻辑右移**（补 0）；shamt = b 低 5bit；shamt≥16 时结果为 0 |

- ADD/SUB 按 16bit 回绕（wrapping），与 MUL 取低 16bit 的位宽约定一致。

## 2. 数据通路接口（已确认）
- **输入**：
  - `a[15:0]`、`b[15:0]`：源操作数，来自寄存器组读端口 A / B
  - `func[3:0]`：来自指令译码
  - 目的寄存器地址 `dst[3:0]`：**单独输出**给寄存器组写端口
- **输出**：
  - `result[15:0]` → 回写 MUX（WB MUX）→ 寄存器组 `wdata`
  - `dst[3:0]` → 寄存器组 `waddr`
  - 回写使能 `wen`：func=0011（NOP）时为 0，其余算逻指令为 1
  - `flags[9:0]` → 标志寄存器

## 3. 标志输出与标志寄存器（已确认）
- ALU 输出 **10 个 1bit 标志**，比较基准为 `a` 与 `b`：

| 顺序 | 标志 | 含义 |
|---|---|---|
| 0 | EQ | a == b |
| 1 | NE | a != b |
| 2 | LT | 有符号 a < b |
| 3 | GT | 有符号 a > b |
| 4 | LE | 有符号 a <= b |
| 5 | GE | 有符号 a >= b |
| 6 | ULT | 无符号 a < b |
| 7 | UGT | 无符号 a > b |
| 8 | ULE | 无符号 a <= b |
| 9 | UGE | 无符号 a >= b |

- **标志寄存器**：10bit，作为线程核心状态部件；**异步复位全 0**；ALU 输出直接写入。
- **更新时机**：**仅 func=0001（SUB/CMP）时更新**标志寄存器；其余 op=0100 指令不改变标志。
- 外部（SEL、BRAF、HLTF 等条件判断）按指令集 Cond 编码（0000=EQ … 1111=FGE）从这 10bit 中选择所需标志。

## 4. 延迟模型（已确认）
- **纯组合逻辑，单周期出结果**。软件模拟中表现为一个函数调用；写回在**周期末（时钟上升沿）统一提交**，与寄存器组规格一致。

## 5. 和线程核心的连接构造
```
指令(op=0100) ──func[3:0]──▶ ALU.func
regfile.rdata_a ──a[15:0]──▶ ALU.a
regfile.rdata_b ──b[15:0]──▶ ALU.b
指令 第一个rx字段 ──dst[3:0]──▶ ALU.dst ──▶ regfile.waddr
ALU.result ──▶ WB MUX ──▶ regfile.wdata
ALU.wen(非0011) ──▶ WB MUX ──▶ regfile.wen
ALU.flags ──▶ 标志寄存器（仅 SUB/CMP 时更新）
周期末上升沿：regfile 提交写回；标志寄存器同拍更新
```

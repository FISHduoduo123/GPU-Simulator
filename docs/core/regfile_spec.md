# 寄存器组（RegFile）—— GPU 模拟器
> 16×16bit 寄存器堆：4 个组合读端口 + 1 个上升沿同步写端口。

- 模块：线程核心内部 / 寄存器组
- 状态：已实现（`src/regfile.rs`）
- 更新日期：2026-11-26
- 依据：`refs/GPU指令集.xlsx`（r0–r15 分区约定）
- 关联：`docs/core/thread_core_spec.md`

## 1. 概述
- 16 个寄存器 `r0–r15`，每个 **16bit**，地址 **4bit**（总存储 256bit）。
- 分区：`r0–r9` 主工作区、`r10–r13` 宏工作区、`r14` 备用、`r15` 栈基址。
- 异步复位，初值全 0。

## 2. 端口与接口
| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| `raddr_a/b/c/d` | 输入 | 4bit ×4 | 4 个读地址 |
| `rdata_a/b/c/d` | 输出 | 16bit ×4 | 4 个读数据（组合输出） |
| `waddr` | 输入 | 4bit | 写地址 |
| `wdata` | 输入 | 16bit | 写数据 |
| `wen` | 输入 | 1bit | 写使能 |
| `clk` | 输入 | 1bit | 上升沿写回 |
| `rst` | 输入 | 1bit | 异步复位 |

## 3. 功能与行为
- **读**：组合逻辑，`rdata_x = regs[raddr_x]`；4 端口可同拍读，允许读同一地址。
- **写**：仅在 `clk` 上升沿且 `wen=1` 时 `regs[waddr] ← wdata`。
- **同周期读写同一寄存器**：沿前读旧值、沿后读新值 → **不需要写旁路（bypass）**。
- **异步复位**：`rst` 有效时立即全部清 0，不受时钟约束。
- **软件模拟模型**：状态 `regs: [u16;16]`；读 = 数组索引（O(1)）；写 = 先暂存 pending，周期末 `tick()` 统一提交；可保留 `prev` 快照用于调试。
- **与核心连接**：读端口 A/B/C/D → 源操作数 1/2/3/4；写端口 ← 回写 MUX（`waddr`←目的寄存器号、`wdata`←回写数据、`wen`←回写有效）。
